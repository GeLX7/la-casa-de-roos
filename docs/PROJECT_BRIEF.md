# La Casa de Roos — Project Brief

**Date:** 2026-06-10 · **Status:** Planning reconciled with owner answers. Repo `GeLX7/la-casa-de-roos` + Vercel project `la-casa-de-roos` created. Phase 1 web MVP scaffold is on PR #1 (`feat/scaffold-web-mvp`) with preview deployments enabled; production remains gated for `main`.

## What this is

An independent, professional booking website for **La Casa de Roos** — four suite/mini-apartment lofts in the historic center of **Arequipa, Peru** (Cercado de Arequipa, one block from Calle Mercaderes, steps from the Plaza de Armas and the Monasterio de Santa Catalina). The units sit inside a commercial building that also houses the YURAKUNA vegan restaurant (1st floor) and the Estudio Museo Lozada Tamayo Coworking (2nd floor, where keys are returned).

The owner currently sells exclusively through Airbnb (4 listings) plus a one-page Carrd link site. This project replaces the Carrd page with a real website that:

1. Presents the same four units beautifully, in Spanish first.
2. Lets visitors check availability and request a reservation directly.
3. Keeps availability in sync with Airbnb in both directions (Airbnb booking blocks the website; website booking blocks Airbnb).
4. Lives on GitHub, deploys on Vercel.

## Core decisions (recommended)

- **Calendar sync (MVP):** two-way iCal — website imports each listing's Airbnb iCal export; Airbnb imports a per-room iCal feed generated by the website. Combined with **request-to-book** (owner confirms manually) to neutralize the 2–3 h Airbnb pull delay. See `architecture/booking-calendar-options.md`.
- **Payments (MVP):** none online. Reservation request → owner confirms → guest pays manually (Yape/Plin/transfer). Owner chose **Culqi** for online checkout — Phase 3 only (no account/API yet; RUC prerequisite to resolve). Stripe is not available to Peruvian businesses. See `architecture/booking-payment-architecture.md`.
- **Prices:** iCal syncs **availability only — never prices**. Until the owner fixes nightly rates, rooms show **"Consultar precio"**; the site must not promise real-time Airbnb price parity. Automatic price sync requires a channel manager/PMS (documented upgrade path).
- **Room naming (owner decision):** Airbnb titles as H1 ("Habitación Corazón Centro Histórico Arequipa"…), Carrd "Suite Queen…" names as subtitles.
- **Web chat + admin replies (owner request):** Phase 2, approval-gated — Supabase Realtime candidate. MVP ships request form + WhatsApp only.
- **Photos:** owner has originals; extracted Airbnb image URLs are internal placeholders only — production launch gates on originals or explicit owner approval (see `research/content-rights-checklist.md`).
- **Stack:** Next.js (App Router) + TypeScript + Tailwind on Vercel; Supabase Postgres for rooms/bookings/blocked dates; Resend for email; `node-ical` + `ical-generator` for sync. See `architecture/recommended-stack.md`.
- **Language:** Spanish first (`es-PE`); English a later phase.
- **Domain:** `lacasaderoos.com` is **available** ($11.25/yr via Vercel as of 2026-06-10). `.pe` optional via a Peruvian registrar (punto.pe).

## Out of scope (for now)

No payment collection, no production database, no production deployment, no domain purchase yet, no Supabase project yet. No Airbnb partnership claims, no scraping beyond the public pages already documented, no Airbnb-hosted assets in production without owner approval.
